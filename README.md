# BITRUSH.ONE

Отдельный адаптивный сайт криптообменного сервиса BitRush. Стили и компоненты созданы для этого проекта, без копирования QuickX.

## Запуск локально

1. Установите Node.js 20.19+ или 22.12+.
2. Откройте папку проекта в VS Code.
3. Выполните:

```bash
npm install
npm run dev
```

Откройте адрес, показанный Vite (обычно http://localhost:5173/).

## Продакшн-сборка

```bash
npm run build
```

Результат в папке `dist`.

## Cloudflare Pages

- Git: отдельный репозиторий BitRush (НЕ репозиторий QuickX).
- Production branch: `main`
- Framework preset: `React (Vite)` / `Vite`.
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
- Привяжите домен `bitrush.one` после успешной сборки, если он принадлежит вам и DNS настроен.

## Кнопки и параметры

- Ссылка менеджера хранится в `src/config.js` (`MANAGER_URL`). Все внешние CTA берут её оттуда.
- Валюты и города в форме — пользовательские параметры **запроса**, не подтверждённые котировки или наличие офисов.
- Сайт **не запрашивает, не принимает и не хранит** деньги, реквизиты или данные посетителей.
- Кнопка «Скопировать запрос» копирует сформированный текст в буфер. Кнопка «Написать менеджеру» открывает предоставленную ссылку. Автоматическая передача сообщения в чат через сторонний редирект не гарантируется.
- Для доступа из некоторых регионов не полагайтесь исключительно на Google Fonts: есть встроенные системные fallback-шрифты.

## Файлы

- `src/App.jsx` — структура, интерактивность и контент сайта.
- `src/styles.css` — тема, адаптив и анимации.
- `src/config.js` — адрес кнопок связи.
- `public/favicon.svg` — фирменная иконка.

Сайт информационный: условия, курс, комиссии, город и возможность обмена уточняются у менеджера. Не публикуйте непроверенные гарантии или фиксированные предложения.
